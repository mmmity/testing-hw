## user story для Discord

### Голосовые каналы
user story: Как участник большого сервера, я хочу общаться с несколькими друзьями одновременно в одном голосовом канале, чтобы играть в игры

Критерии приемки:
- пользователь может подключиться к голосовому каналу
- после подключения пользователь отображается среди участников канала
- пользователь не может подключиться к нескольким каналам одновременно на одном сервере
- пользователь в канале может включить выключенный и выключить включенный микрофон
- при выключенном микрофоне пользователя не слышат другие
- при включенном микрофоне пользователя слышат другие пользователи
- пользователь слышит других участников с включенным микрофоном

### Модераторы
user story: как модератор сервера, я хочу иметь возможность мутить и банить нарушителей спокойствия, чтобы поддерживать порядок на сервере

Критерии приемки:
- пользователь без соответствующих прав не может выполнить операцию мута или бана
- пользователь с текстовым мутом в канале не может писать текстовые сообщения в этот канал до конца мута
- пользователь с баном не может зайти в голосовой канал
- если пользователь находится в голосовом канале, при бане из него он автоматически его покидает
- замученным и забаненным пользователям показывается причина бана и мута, а так же время их окончания
- для бессрочного бана/мута пользователю показывается, что ограничение бессрочное]
